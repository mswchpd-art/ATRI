# 角色卡开场白设计

## 开场白是什么

开场白是角色卡的首楼（0楼）, 相当于一本小说的起点.

它要做到:
- 让 {{user}} 有行动目标, 知道接下来怎么玩
- 固定后续文风, 延缓文风劣化, 减少八股
- 交代故事背景、设定、人物关系

## 开场白的目的

### 给引子, 让故事发生

角色扮演不需要像小说那样写多强的开头, 但**最基本的事必须做到**: 给一个引子, 让玩家玩得下去, 让他有一个目标.

如果开场白没有制造矛盾、没有创造目标, 玩家拿到角色卡会不知所措.

**必须主动制造事件让故事发生.** 即使是本子, 让两个人发生关系也需要铺垫理由, 不可能毫无道理地直接进入正题. 例如:
- 催眠 app 的卡 → 铺垫 user 使用它的动机（被霸凌、妹妹态度差、性压抑等）
- 这是最基础的引子, 让玩家立刻知道这是什么故事、自己要去做什么

目标可以很简单, 但不能没有.

### 交代背景与人物关系

简单讲必要的设定, 自然融入正文, 让玩家知道故事最基本的信息:
- 故事发生在现代/古代? 国内/国外?
- 有无超自然要素?
- 人物之间是什么关系?

### 固定后续文风

不同模型都多少会吃首楼的文风和结构（deepseek、gemini、claude 特别吃开场白）, 所以**必须在开场白的文风上花心思打磨**:
- 有人爱玩不抢话 → 首楼最好不写 {{user}} 说的话
- 有人喜欢对话多 → 开场白的对话可以多写
- 喜欢特定文风 → 就用这个文风写开场白, 等于直接塞文风示例给模型学

**八股**: 开场白主动规避 LLM 爱用的八股句式, 后续会很大程度延缓文风劣化. 如果开场白就包含投石、指节泛白这类八股, 玩的时候很容易出现.

## 开场白的三种写法

### 1. 完全手写

自己写最好, 也最不容易八股. 不需要觉得自己没能力写——**只要做到没有 LLM 的八股, 就比 LLM 写的强**. 放手写, 大白话也没关系.

不知道写什么 → 可以先让 AI 写, 然后自己对着情节用自己的话再写一遍.

### 2. 半手写

AI 写好后, 人为去掉八股词、修改不喜欢的地方. 只需去掉八股, 非常简单.

但毕竟是 AI 写的东西, 文风劣化速度比手写的快一些. 可以让 GPT/Claude 写开场白, 用 Gemini 玩——用不同模型生成、不同模型玩, 效果不错.

### 3. 大纲开场白

不提供具体文本, 提供一份情节大纲.

主观看法: 这种写法不太推荐——它起不到固定文风的作用. Gemini 这类语料多的模型 roll 开场白还不错; Claude 语料较少, 自己发挥写得很糟糕.

## 写开场白时的检查

- [ ] 有没有给 {{user}} 一个行动目标/引子? 玩家知道接下来做什么吗?
- [ ] 有没有交代必要的故事背景（时代/地点/超自然要素）和人物关系?
- [ ] 文风是否符合目标玩家的偏好（不抢话/多对话/特定风格）?
- [ ] 有没有主动规避八股（模糊词、陈旧比喻、八股微表情、极端情绪词、否定转折句）?
- [ ] 是否主动制造了让故事发生的矛盾或事件, 而不是平铺直叙?
